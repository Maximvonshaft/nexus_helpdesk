# Operator Browser Evidence

Canonical browser evidence covers the authenticated operator product at representative 375, 768, 1024, 1280, 1366 and 1440 pixel widths. Evidence must include normal, loading, empty, degraded, conflict and repair-required states, keyboard/focus behavior, 200% text enlargement, representative-volume queues and timelines, and deterministic screenshots.

The browser suite uses the Playwright-pinned Chromium engine declared in `BROWSER_SUPPORT.md`. Screenshot and trace output is evidence, not a second product or a design-token authority.
